# 🛒 Dynamic E-Commerce Product & Inventory Catalog

A full-stack e-commerce catalog and inventory management web application built with **Flask**, **SQLite**, and modern JavaScript. The application allows users to browse products, dynamically filter items by category, search by title, filter by price range, and track real-time stock levels with formatted Indian Rupee (₹) pricing.

---

## ✨ Features

- **Dynamic Product Filtering:** Filter items by categories, search keywords, and maximum price in real-time.
- **Inventory Tracking:** Real-time visual stock indicators (In Stock, Low Stock, Out of Stock).
- **RESTful API:** Clean API endpoints built with Python Flask for data queries[cite: 1].
- **Indian Rupee Support:** Currency formatting configured specifically for INR (₹).
- **Responsive UI:** Clean, intuitive UI built with standard HTML5, CSS3, and modern JavaScript[cite: 1].

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-CORS[cite: 1]
- **Database:** SQLite[cite: 1]
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API)[cite: 1]
- **Deployment:** Render (Gunicorn WSGI server)[cite: 1]
